# 流浪冒険者TRPG / Wandering Adventurer TRPG

オフラインで動作する単一HTMLのTRPGプロジェクトです。

## プレイ用ファイル

| 種別 | ファイル | 更新方針 |
| --- | --- | --- |
| **Stable（安定版）** | [`index.html`](./index.html) | QA受入と正式昇格のときのみ更新。開発途中の変更は反映しません。 |
| **Development（開発試遊版）** | [`dev.html`](./dev.html) | 変更の実装・QA受入後に随時更新。予告なく内容やゲームバランスが変わる可能性があります。 |

2026-10-13時点: Stableは **V5.0 Phase 2 試作安定版（Internal Stable）** です。昇格時点では `index.html` と `dev.html` のゲーム内容は同一です。主要ループを試遊検証した開発基準版ですが、9幕の全分岐・Android実機・実URLでの保存持続試験などは未完了で、完成品としての公開承認ではありません。

現在、このリポジトリは **非公開** です。一般向け公開・配布およびGitHub Pages上の動作は、別途審査する事項です。

## 変更とリリースの考え方

1. Stableを変更せずに、開発候補を別途作成・試験します。
2. QAで受け入れた開発候補を `dev.html` に反映し、更新履歴をGitのコミットに残します。
3. 新しいStableを確定したときだけ `index.html` を更新します。
4. StableとDevelopmentは `main` ブランチ上で並行提供し、どちらも上書き前に旧版を復元できる状態を維持します。
5. 更新時にはDrive側の同期コピーとの内容一致を確認します。

開発途中の全変更をStableへ自動反映するものではありません。また、未検証の作業中コードをそのまま `dev.html` に投入しません。

## セーブデータについて

現行 `index.html` と `dev.html` は同じ保存キー（`wander_trpg_v300_f1dev_html`）とSave Version 11を使用します。同じブラウザの同じオリジンで実行した場合、保存が共有されることがあります。別のURL、別のオリジン、`file://` などでは保存領域が異なり、以前の保存が自動で見つからないことがあります。版の切替・再開前には、ゲーム内のSaveファイル書き出し機能でバックアップしてください。

ゲーム本体のコードと実行に必要なファイルをGitHubに置き、内部の企画・仕様・QA記録などは開発用の管理領域に保管します。本READMEはプレイヤー向けの版説明です。
