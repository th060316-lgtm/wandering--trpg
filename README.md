# 流浪冒険者TRPG

**道を選び、仲間と旅をする。選択が世界に残る、オフラインのブラウザRPG。**

探索・依頼・交渉・戦闘・生活を、自分のペースで進める個人制作ゲームです。

## 🎮 まず遊ぶ

**[V6.0 安定版 `index.html`](./index.html)** — はじめての方はこちら。

**[開発試遊版 `dev.html`](./dev.html)** — 更新途中の機能を試したい方向け。

GitHubでHTMLファイルを表示しただけではゲームは起動しません。ファイル表示画面の **Download raw file** で保存し、ダウンロードした `.html` をブラウザで開いてください。インストールやアカウント登録は不要です。

## ⚔️ どんなゲーム？

- **冒険を選ぶ**：9地域を旅し、街で依頼を引き受け、分岐路で進む道を選ぶ。
- **生き延びる**：食料・水・疲労・装備を管理し、戦うか、交渉するか、迂回するか決める。
- **仲間と戦う**：8列×3行の戦術盤面で、仲間の位置と射程を考える。

## 💾 セーブと動作環境

ゲーム内で進行を保存できます。保存領域はブラウザ・URLごとに異なるため、環境やバージョンを切り替える前にゲーム内の保存データ書き出しでバックアップしてください。

Chromium系ブラウザで基本動作を確認しています。その他の環境では正常に動作しない場合があります。
