# 流浪冒険者TRPG

**街から旅立ち、道を選ぶ。仲間と生き延びながら、変わっていく世界を歩く。**

オフラインで遊べる、個人制作のブラウザRPGです。探索・依頼・交渉・戦闘・生活を、自分のペースで楽しめます。

**V6.0 無料α体験版（内部安定版）｜現在は公開準備中**

## 🎮 はじめて遊ぶ方へ

1. **[安定版のゲームファイル `index.html` を開く](./index.html)**
2. GitHubのファイル画面で **Download raw file（ダウンロード）** を選び、HTMLを保存
3. 保存した `index.html` をブラウザで開いてゲーム開始

> **注意：** GitHubのコード表示画面ではゲーム自体は動きません。現在このリポジトリは **Private** なので、ファイルの取得には閲覧権限が必要です。ゲーム本体へのアカウント登録は不要です。

## 🗺️ 冒険でできること

- **9地域を旅する**：依頼を受け、道を選び、住人の話を聞く
- **危険を切り抜ける**：食料と水を管理し、戦闘・交渉・迂回から決める
- **仲間と戦う**：8列×3行の戦場で位置・射程・障害物を考える

## 💾 セーブと動作環境

ゲーム内で保存できます。ブラウザや開く場所が変わると保存データが引き継がれないことがあります。**長く遊ぶ場合は、ゲーム内の保存データ書き出しでバックアップしてください。** 安定版と開発版のセーブ領域が共有される場合もあるため、切り替え前にもバックアップを推奨します。

Chromium系ブラウザで基本動作を確認済み。その他の環境は未検証で、正常動作を保証するものではありません。

## 🔧 開発版を試す

[開発試遊版 `dev.html`](./dev.html) では、更新途中の機能が含まれる場合があります。初めて遊ぶ方には上の安定版をおすすめします。

このリポジトリに置くのはゲームの実行ファイルと最低限の案内のみです。企画書・会議録・QA記録・旧版は開発用の別保管先で管理しています。
