# 流浪冒険者TRPG

**英雄でなくても、冒険者として生きていける。**

戦うか、交渉するか、引き返すか。  
危険な土地へ向かう日もあれば、町で働いて暮らす日もある。  
あなたの選択を積み重ね、自分だけの旅を続ける、**無料・オフラインのブラウザRPG**です。

## 🎮 ゲームを始める

**[ゲーム本体（index.html）を入手する](./index.html)**

1. 上のリンクから `index.html` のファイル画面へ進みます。
2. GitHubの **Download raw file（ダウンロード）** を選び、HTMLファイルを保存します。
3. 保存した `index.html` をブラウザで開くと、ゲームを始められます。

※ GitHubのソースコード表示画面ではゲームを直接プレイできません。HTMLファイルを保存して開いてください。  
※ ゲームを始めるためのアカウント登録や常時ネット接続は必要ありません。

## 🗺️ このゲームでできること

### 行き先も、旅の仕方も選ぶ
9つの地域を旅し、依頼を受けるか、自由に出発するかを決められます。最短で急ぐ、安全を優先する、補給を重視する――経路の選び方によって、時間・危険・消耗の判断が変わります。現地では探索、調査、採集、野営、住人との会話が待っています。

### 戦う以外の生き方がある
町では日雇い仕事や採集で生活費を稼ぎ、休養し、装備を整えることもできます。すべての問題を剣で解決する必要はありません。危険な依頼に挑むのも、準備を重ねるのも、冒険者としての選択です。

### 仲間と考えて戦う
戦闘は**8列×3行のマス目**を使うターン制。味方・中立・敵の区画を見ながら、位置取り、射程、障害物、仲間の行動を考えます。仲間の自律行動もあり、状況によっては交渉や撤退を選べます。主人公が倒れても、仲間が残っていれば戦いは続きます。

### 旅の出来事が次の判断につながる
地域ごとの噂や人々の動き、街道での事件、交易や物資の状況が冒険に関わります。依頼や道中の出来事をどう扱うかによって、得られる情報や資源、次にできることが変わります。

### 帰ってくるまでが冒険
食料、水、疲労、負傷、装備の消耗を考え、行きだけでなく帰り道も見据える必要があります。大きな成果を持ち帰るか、危険を避けて無事に帰還するか。**生き延びるための判断そのもの**を楽しむゲームです。

## 🧭 初めての旅のおすすめ

1. 「拠点」で食料・水・仲間・装備を確認する。
2. 「冒険」で依頼か自由遠征を選び、目的地と移動方針を決める。
3. 現地では調査・会話・採集などを試し、危険なら撤退や帰還を考える。
4. 町に戻ったら休養・補給・整備を行い、次の旅へ出発する。

## 💾 セーブと動作環境

- ゲームの進行はブラウザ内で保存・再開できます。
- ブラウザや保存場所を変えると、セーブデータが引き継がれないことがあります。**ゲーム内の保存データ書き出し機能でバックアップ**することをおすすめします。
- Chromium系ブラウザで基本動作を確認しています。その他の環境では動作が異なる可能性があります。
- ブラウザ上で動く個人制作ゲームです。プレイは無料です。

## 🔧 開発版について

通常のプレイには **[index.html](./index.html)** をおすすめします。**[dev.html](./dev.html)** は開発確認向けで、更新途中の要素が含まれる場合があります。切り替える前にはセーブデータをバックアップしてください。
